# Captions

`normalize_subtitles(text, format)` reads SRT, WebVTT (`vtt`/`webvtt`), and ASS/SSA into `CaptionCue` objects with timestamps in seconds relative to the original media timeline. It removes subtitle styling, decodes HTML entities, normalizes horizontal whitespace, and preserves speaker line breaks. Malformed cue blocks raise an error so the importer can try another track or transcription. Ordinary WebVTT preserves repeated dialogue. Only pass `rolling=True` for a verified rolling auto-caption track; overlapping prefix updates replace the earlier cue at the new cue's start, while the full later text remains visible through its end. `caption_at(cues, timestamp, offset=0)` uses half-open cue intervals: the start is included, the end is excluded, and silence returns an empty string. A positive offset delays display.

`transcribe_media(media_path, cache_path, backend=..., language=...)` supports `disabled` and optional local faster-whisper (`local` or `local:<model>`; default model `small`). The package is imported only when a cache miss needs inference. Install it separately on the host that performs transcription. The whole media file is transcribed once using voice activity detection and word timestamps. Consecutive words within a segment form short phrases; a speech gap over 0.5 seconds starts a new cue. Captions are cached atomically as JSON, keyed by the media file's SHA-256 digest, model, and language. Reusing an unchanged file and configuration avoids inference; changing any of those inputs refreshes the cache. `language="auto"` asks faster-whisper to detect language, though the track metadata retains `auto`.

The GPU worker's current Compose stack has no speech transcription service. `remote` therefore raises an explicit unavailable error, and `endpoint` is not accepted for local transcription. The player can select an external subtitle track first, then use local ASR only if no suitable track exists and the operator has enabled it. The import flow should write normalized cues with their source and language using `CaptionTrack.model_dump_json()`; playback can restore them with `CaptionTrack.model_validate_json()`.
